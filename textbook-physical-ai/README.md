# Physical AI & Humanoid Robotics – Essentials

An AI-native textbook on Physical AI & Humanoid Robotics built with Docusaurus and deployed to GitHub Pages.

## Overview

This textbook provides a comprehensive introduction to Physical AI and Humanoid Robotics, covering foundational concepts, design principles, perception systems, AI control, and locomotion. The content is structured as 6 chapters with clear learning objectives, examples, and references.

## Chapters

1. Introduction to Physical AI
2. Foundations of Robotics: Systems, Structure & Core Mechanisms
3. Human-Inspired Design Principles in Humanoid Robotics
4. Perception Systems in Humanoids
5. AI, Deep Learning & Control Systems
6. Humanoid Locomotion and Manipulation

## Development

To run the textbook locally:

```bash
npm start
```

To build for production:

```bash
npm run build
```

To serve the built site locally:

```bash
npm run serve
```

## Deployment

The site is configured for GitHub Pages deployment. When pushed to the main branch, it will automatically deploy via GitHub Actions.
