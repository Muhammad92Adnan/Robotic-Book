# Data Model: Textbook Generation

**Feature**: 1-textbook-generation
**Date**: 2025-12-08
**Status**: Complete

## Overview

This document defines the data model for the AI-native textbook on Physical AI & Humanoid Robotics. The textbook is structured as static markdown files with frontmatter metadata, processed by Docusaurus to generate the final website.

## Chapter Entity

### Structure
- **Entity Name**: Chapter
- **Description**: A single chapter of the textbook containing educational content
- **Location**: `/docs/chapter-{n}-{slug}/chapter.md`

### Fields
- **chapter_id** (string): Unique identifier for the chapter (e.g., "chapter-1", "chapter-2")
- **section_id** (string): Sequential identifier for ordering (1-6)
- **title** (string): Human-readable title of the chapter
- **learning_objectives** (array of strings): 3-5 learning objectives for the chapter
- **difficulty_level** (string): Academic difficulty level (e.g., "beginner", "intermediate")
- **example_count** (number): Number of examples included in the chapter
- **images** (boolean): Whether the chapter includes images/diagrams
- **translation_ready** (boolean): Whether the chapter is ready for translation
- **apa_references** (array of objects): APA-formatted references for the chapter
- **content** (string): The main markdown content of the chapter

### Validation Rules
- chapter_id must follow the pattern "chapter-{n}" where n is 1-6
- title is required and must be 10-100 characters
- learning_objectives must contain 3-5 items
- difficulty_level must be one of: "beginner", "intermediate", "advanced"
- example_count must be 0 or greater
- apa_references must follow APA 7th edition format
- content must be between 800-1500 words

### Relationships
- Each Chapter belongs to exactly one Textbook
- Chapters are ordered sequentially from 1 to 6
- Chapters may reference shared assets in `/static/img/`

## Textbook Entity

### Structure
- **Entity Name**: Textbook
- **Description**: The complete textbook containing 6 chapters
- **Location**: Root of Docusaurus site

### Fields
- **title** (string): "Physical AI & Humanoid Robotics – Essentials"
- **subtitle** (string): Optional subtitle for the textbook
- **author** (string): Author attribution
- **version** (string): Version identifier
- **chapters** (array of Chapter references): Ordered list of chapters 1-6
- **created_date** (date): Date of textbook creation
- **last_updated** (date): Date of last content update

### Validation Rules
- Must contain exactly 6 chapters
- Chapters must be numbered sequentially 1-6
- Title must match "Physical AI & Humanoid Robotics – Essentials"
- All chapters must pass individual validation

## Asset Entity

### Structure
- **Entity Name**: Asset
- **Description**: Static assets (images, diagrams) used in chapters
- **Location**: `/static/img/`

### Fields
- **asset_id** (string): Unique identifier for the asset
- **filename** (string): Original filename
- **filetype** (string): File extension (svg, png, jpg)
- **size** (number): File size in bytes
- **alt_text** (string): Accessibility description
- **usage_count** (number): Number of chapters using this asset
- **chapters** (array of strings): List of chapters using this asset

### Validation Rules
- File size must be under GitHub Pages limits (typically <25MB)
- SVG files preferred for diagrams
- Alt text required for accessibility
- File names must be URL-safe

## Frontmatter Schema

Each chapter.md file must include the following frontmatter:

```yaml
chapter_id: "chapter-1"
section_id: 1
title: "Introduction to Physical AI"
learning_objectives:
  - "Define Physical AI and distinguish it from Virtual AI"
  - "Identify real-world applications of Physical AI"
  - "Understand the scope of Physical AI systems"
difficulty_level: "beginner"
example_count: 3
images: true
translation_ready: true
apa_references:
  - author: "Author, A. A."
    year: "2023"
    title: "Title of the work"
    publisher: "Publisher"
    url: "https://example.com"
```

## Navigation Structure

### Auto-generated Sidebar
- The sidebar is automatically generated based on the `/docs/` directory structure
- Chapters appear in sequential order (1-6)
- Each chapter has a clear, descriptive title in the navigation
- Breadcrumbs are automatically generated by Docusaurus

### URL Structure
- Base URL: `https://[username].github.io/[repository]/`
- Chapter URLs: `/docs/chapter-{n}-{slug}` (e.g., `/docs/chapter-1-introduction`)
- Asset URLs: `/img/{filename}`

## Content Requirements

### Learning Objectives
- Must be specific and measurable
- Should use action verbs (define, identify, explain, analyze)
- Limited to 3-5 per chapter to maintain focus
- Must align with chapter content

### Content Structure
- Headings and subheadings for clear organization
- Bullet points for key concepts
- Examples to illustrate concepts
- APA citations for factual claims
- References list at chapter end

### Quality Standards
- Professional, clear language
- Technical accuracy verified
- Appropriate for target audience (beginner-intermediate)
- Consistent formatting across all chapters
- No placeholder text or incomplete sections
