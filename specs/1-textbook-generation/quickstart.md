# Quickstart Guide: Textbook Generation

**Feature**: 1-textbook-generation
**Date**: 2025-12-08
**Status**: Complete

## Overview

This guide provides step-by-step instructions to set up and run the AI-native textbook on Physical AI & Humanoid Robotics. The textbook is built using Docusaurus and deployed to GitHub Pages.

## Prerequisites

- Node.js LTS (v18 or higher)
- npm or pnpm package manager
- Git
- GitHub account (for deployment)

## Setup Instructions

### 1. Clone or Initialize Repository

```bash
# If starting fresh
npx create-docusaurus@latest textbook-physical-ai classic

# If working with existing repository
git clone <your-repo-url>
cd <your-repo-directory>
```

### 2. Install Dependencies

```bash
npm install
# OR if using pnpm
pnpm install
```

### 3. Verify Installation

```bash
npm run start
```

This should start the development server and open the default Docusaurus site in your browser at `http://localhost:3000`.

## Creating the Textbook Structure

### 1. Set Up Chapter Directories

Create the following directory structure in your project root:

```
docs/
├── chapter-1-introduction/
│   └── chapter.md
├── chapter-2-foundations/
│   └── chapter.md
├── chapter-3-human-design/
│   └── chapter.md
├── chapter-4-perception/
│   └── chapter.md
├── chapter-5-ai-control/
│   └── chapter.md
└── chapter-6-locomotion/
    └── chapter.md
```

### 2. Configure Docusaurus

Update `docusaurus.config.js` with your textbook settings:

```javascript
// docusaurus.config.js
module.exports = {
  title: 'Physical AI & Humanoid Robotics – Essentials',
  tagline: 'An AI-native textbook on Physical AI & Humanoid Robotics',
  url: 'https://<your-username>.github.io',
  baseUrl: '/<your-repository-name>/',
  onBrokenLinks: 'throw',
  onBrokenMarkdownLinks: 'warn',
  favicon: 'img/favicon.ico',

  // GitHub Pages deployment configuration
  organizationName: '<your-github-username>',
  projectName: '<your-repository-name>',
  deploymentBranch: 'gh-pages',

  presets: [
    [
      'classic',
      /** @type {import('@docusaurus/preset-classic').Options} */
      ({
        docs: {
          sidebarPath: require.resolve('./sidebars.js'),
          editUrl: 'https://github.com/<your-username>/<your-repository-name>/edit/main/',
        },
        theme: {
          customCss: require.resolve('./src/css/custom.css'),
        },
      }),
    ],
  ],

  themeConfig: {
    navbar: {
      title: 'Physical AI & Humanoid Robotics',
      logo: {
        alt: 'Textbook Logo',
        src: 'img/logo.svg',
      },
      items: [
        {
          type: 'doc',
          docId: 'chapter-1-introduction/chapter',
          position: 'left',
          label: 'Textbook',
        },
        {
          href: 'https://github.com/<your-username>/<your-repository-name>',
          label: 'GitHub',
          position: 'right',
        },
      ],
    },
    footer: {
      style: 'dark',
      copyright: `Copyright © ${new Date().getFullYear()} Physical AI & Humanoid Robotics – Essentials. Built with Docusaurus.`,
    },
  },
};
```

## Creating Chapter Content

### 1. Chapter Template

Each chapter file (`chapter.md`) should follow this template:

```markdown
---
chapter_id: "chapter-1"
section_id: 1
title: "Introduction to Physical AI"
learning_objectives:
  - "Define Physical AI and distinguish it from Virtual AI"
  - "Identify real-world applications of Physical AI"
  - "Understand the scope of Physical AI systems"
difficulty_level: "beginner"
example_count: 3
images: true
translation_ready: true
---

# Introduction to Physical AI

## Learning Objectives

After reading this chapter, you will be able to:
- Define Physical AI and distinguish it from Virtual AI
- Identify real-world applications of Physical AI
- Understand the scope of Physical AI systems

## What is Physical AI?

[Your chapter content here with headings, subheadings, and bullet points]

## Key Takeaways

- Summary point 1
- Summary point 2
- Summary point 3

## References

- Author, A. A. (Year). Title of the work. Publisher. URL if applicable
- Author, B. B. (Year). Title of the work. Publisher. URL if applicable
```

### 2. Content Guidelines

- Keep chapters between 800-1500 words
- Use H1 for main title, H2 for sections, H3 for subsections
- Include bullet points for key concepts
- Add APA citations for factual claims
- Include 1-2 lightweight SVG diagrams if needed
- Ensure content is professional and accessible

## Deployment to GitHub Pages

### 1. GitHub Actions Setup

Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  deploy:
    name: Deploy to GitHub Pages
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 18
          cache: npm

      - name: Install dependencies
        run: npm install
      - name: Build website
        run: npm run build

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./build
          publish_branch: gh-pages
```

### 2. Manual Deployment

```bash
# Deploy to GitHub Pages
npm run deploy
```

## Troubleshooting

### Common Issues

1. **Sidebar not showing chapters**: Verify `sidebars.js` configuration and directory structure
2. **Images not loading**: Check image paths are relative to `/static/` directory
3. **Build errors**: Run `npm run build` to see specific error messages
4. **GitHub Pages not updating**: Verify deployment branch is set to `gh-pages` in repository settings
